# 🌦️ 台灣天氣可愛手繪風 Chrome 擴充功能 (Taiwan Weather Chrome Extension)

[English](./README.en.md) | 繁體中文

> **當前版本**：v2.3.9

這是一款專為台灣設計的 Chrome 瀏覽器天氣擴充功能。採用**溫馨可愛的手繪插畫風格**，並支援細緻到**鄉鎮區級別**的即時天氣與一週預報，讓你在瀏覽網頁之餘，也能隨時掌握全台各地的天氣變化！

## ✨ 核心特色

* 🌐 **多國語言支援 (i18n)**：完美支援**繁體中文 (Traditional Chinese)** 與 **英文 (English)** 雙語介面。套件能自動感應瀏覽器語系進行顯示，亦可在設定面板中手動切換。
* 🔍 **雙語搜尋與動態翻譯**：搜尋框支援中文及英文拼音（Pinyin）模糊搜尋全台縣市與鄉鎮區；天氣狀況 (Wx)、風向、空氣品質指標 (AQI) 等所有氣象資訊均提供高品質的雙語翻譯對照。
* 📍 **細緻定位**：支援全台灣 22 個縣市、所有鄉鎮市區。
* 🌦️ **即時天氣資訊**：提供當前溫度、體感溫度、相對濕度、降雨機率、風力級別與風向。
* 🌧️ **雨量防災警示**：整合中央氣象署自動雨量站 API，即時顯示今日累積降雨量。當過去 1 小時降雨量（時雨量）達 30 mm 或以上時，UI 會自動切換並啟動紅色呼吸燈閃爍警戒。
* 🔔 **氣象警特報整合**：即時抓取中央氣象署官方警特報 API，支援豪雨、強風、低溫、高溫、颱風等官方警示，並在主畫面以醒目的警告橫幅顯示。
* 📊 **今日智慧摘要**：根據當前溫度、降雨機率、時雨量、AQI 及警特報，自動產生一句話摘要，一眼掌握當日天氣重點。
* 🌿 **即時空氣品質 (AQI & PM2.5)**：自動監測站媒合。點擊 AQI 卡片可展開詳細污染物數據（PM10、O₃、NO₂、CO、SO₂）與個人化健康建議。
* 📅 **一週天氣預報**：直觀的 7 天天氣預報，特別突顯「明天」；降雨機率依高低以顏色分級；每張預報卡均標示資料來源。
* 🎨 **療癒手繪設計**：精心調配的手繪淺色與深色主題，搭配可愛的手繪風邊框與微動畫。
* 🏷️ **常用地區快速切換**：整合模糊搜尋框，打字即時篩選，一鍵儲存常用鄉鎮。
* 🌡️ **工具列圖示即時溫標**：瀏覽器工具列圖示直接顯示主地區的當前溫度，並根據氣溫自動變換背景顏色。
* ⚡ **省流快取與效能優化**：內建 Service Worker 背景定時快取與背景代理 Fetch 機制，避免重複請求，解決 Manifest V3 下 Popup 的跨網域與權限限制。

> 💡 關於詳細的版本更新與歷史紀錄，請參閱 [更新日誌 (CHANGELOG.md)](./CHANGELOG.md)。

## 🛠️ 技術架構

* **前端核心**：HTML5, JavaScript (ES6+), Vanilla CSS（採用手繪風格卡片與靈活佈局）
* **擴充功能標準**：Chrome Extension Manifest V3
* **背景服務**：Service Worker (`background.js`)、Chrome Alarms API、Chrome Storage API
* **氣象數據來源**：中華民國交通部中央氣象署 (CWA) 開放資料 API（主數據源）
* **後半週降雨機率補充**：[Open-Meteo API](https://open-meteo.com/)（提供第 4~7 天的降雨機率，免申請金鑰）
* **空氣品質數據來源**：中華民國環境部 (MOENV) 開放資料 API

## 📦 安裝與設定指南

<details>
<summary><b>🛠️ 點擊展開：手動安裝教學 (Unpacked Extension Setup)</b></summary>

1. **下載本專案**：
   * 點擊本倉庫右上角的 `Code` -> `Download ZIP` 並解壓縮，或者使用 Git 複製倉庫：
     ```bash
     git clone https://github.com/xiaomaowei/taiwan_weather_chrome.git
     ```
2. **開啟 Chrome 擴充功能頁面**：
   * 在 Chrome 網址列輸入 `chrome://extensions/` 並回車。
3. **啟用開發者模式**：
   * 將擴充功能頁面右上角的**「開發者模式」**開關切換為啟用。
4. **載入擴充功能**：
   * 點擊左上角的**「載入未封裝擴充功能」**按鈕。
   * 選擇本專案的解壓縮資料夾（包含 `manifest.json` 的該層目錄）。
5. **固定至工具列**：
   * 點擊 Chrome 右上角的拼圖圖示 🧩，找到「台灣天氣」，點擊圖釘按鈕將其固定在工具列，以便隨時查看即時溫度！

</details>

<details>
<summary><b>🔑 點擊展開：申請與設定 CWA API Key (氣象)</b></summary>

為了能順利獲取最即時的氣象資訊，建議設定您專屬的中央氣象署授權碼：

1. **申請授權碼**：
   * 前往 [交通部中央氣象署開放資料平台](https://opendata.cwa.gov.tw/index) 註冊免費帳號。
   * 登入後在個人帳戶的「取得授權碼」頁面中複製您的 `API Key` (格式如：`CWA-XXXXXX`)。
2. **在擴充功能中設定**：
   * 點開瀏覽器上的台灣天氣擴充功能。
   * 點擊右上角的**「齒輪」設定按鈕**展開設定面板。
   * 在「CWA API 授權碼」欄位貼上您申請的授權碼，點擊**「儲存設定」**。
   * *(註：本專案未預設金鑰，請務必填寫以獲取氣象資訊，或在設定中開啟「示範模式」進行體驗。)*

</details>

<details>
<summary><b>🔑 點擊展開：申請與設定 MOENV API Key (空氣品質)</b></summary>

本功能已新增即時空氣品質顯示，若要正常獲取最精確的 AQI 與 PM2.5 數據，建議設定您的環境部 API 金鑰：

1. **申請授權碼**：
   * 前往 [環境部開放資料平台](https://data.moenv.gov.tw/api-term) 註冊免費帳號並申請 API Key。
2. **在擴充功能中設定**：
   * 點開擴充功能，點擊右上角**「齒輪」設定按鈕**。
   * 在「環境部 API 金鑰」欄位中貼上您申請的 Key，並點擊**「儲存設定」**。
   * *(註：本專案未預設金鑰。若未設定金鑰，卡片會顯示「🌿 點此設定環境部 API 金鑰以顯示空氣品質」提示引導您完成設定。)*

</details>

## 📢 氣象資料限制與說明

<details>
<summary><b>💧 點擊展開：一週預報降雨機率的資料融合機制</b></summary>

* **前 3 天使用中央氣象署 (CWA) 官方數據**：依據中央氣象署逐 12 小時七天預報資料特性，降雨機率（ProbabilityOfPrecipitation）僅提供未來前 3 天的預測數值。本套件會優先顯示此官方數據。
* **後 4 天（第 4~7 天）自動補充自 Open-Meteo API**：由於氣象署 API 在後半週資料集中不提供降雨機率，套件會依據您所選擇的鄉鎮市區座標，在背景自動向免金鑰的 **Open-Meteo API** 請求該地區的最大日降雨機率（`precipitation_probability_max`）來進行補充。
* **降雨機率容錯設計**：若 Open-Meteo 請求失敗或網路異常，後半週降雨機率將會優雅降級顯示為 `💧--`，不會影響其他天氣資訊的呈現。

</details>

<details>
<summary><b>🌧️ 點擊展開：即時雨量數據與警戒機制說明</b></summary>

* **資料來源**：中央氣象署自動雨量站觀測資料（`O-A0002-001`），更新頻率約每 **10 分鐘**一次。
* **今日累積**：`RainfallElement.Now.Precipitation` 欄位，代表每天凌晨 **00:00 清零**後至當下的累積降雨量。
* **時雨量警戒**：`RainfallElement.Past1hr.Precipitation` 欄位，代表過去 1 小時的累積降雨量。當時雨量 **≥ 30 mm**（達大雨至豪雨級別）時，UI 自動切換為顯示「時雨量」並啟動紅色呼吸燈警戒提示。
* **雨量容錯設計**：若自動雨量站 API 請求失敗，雨量欄位會優雅降級顯示為 `-- mm`，不影響主天氣資訊的呈現。
* **特殊代碼說明**：`T`（微量降雨，不足以計量）；`-98`（連續 6 小時無降雨，顯示為 0.0 mm）；`-99` / `X`（儀器故障或資料缺值，顯示為 0.0 mm）。

</details>

<details>
<summary><b>⏱️ 點擊展開：即時天氣觀測與測站媒合機制</b></summary>

* **資料來源**：中央氣象署局屬氣象站及無人自動氣象站即時觀測資料（`O-A0003-001`），更新頻率約每 **10 分鐘**一次。
* **測站媒合機制**：套件會優先透過經緯度計算，找出離您所選鄉鎮市區中心座標「直線距離最短」的有效觀測站；若無座標資料，則以鄉鎮名稱進行模糊比對。
* **觀測項目**：包含當前氣溫、濕度、風速、風向、當前天氣狀況（如陰、晴、雨等）。套件會依據測站即時的氣溫、濕度、風速自動計算「體感溫度」（Apparent Temperature）。
* **降級容錯機制**：當所選測站的某個欄位無效（例如故障或缺值，代碼如 `-99`）或 API 請求失敗時，套件會自動降級採用 CWA 鄉鎮預報的預測值（`F-D0047` 系列）來補足，確保畫面資料不中斷。

</details>


## 🎨 介面與主題切換

本套件支援**「手繪淺色主題」**與**「手繪深色主題」**。系統會根據您作業系統的深色模式設定自動套用，您也可以隨時在設定面板中手動切換：

* **淺色模式**：溫暖舒服的手繪羊皮紙米色底、炭灰色手繪線條與粉嫩的天氣插圖。
* **深色模式**：護眼的深夜黑板深藍底、明亮的手繪白線條。
