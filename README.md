# 🌦️ 台灣天氣可愛手繪風 Chrome 擴充功能 (Taiwan Weather Chrome Extension)

[English](./README.en.md) | 繁體中文

> **當前版本**：v2.3.7

這是一款專為台灣設計的 Chrome 瀏覽器天氣擴充功能。採用**溫馨可愛的手繪插畫風格**，並支援細緻到**鄉鎮區級別**的即時天氣與一週預報，讓你在瀏覽網頁之餘，也能隨時掌握全台各地的天氣變化！

## ✨ 核心特色

* 🌐 **多國語言支援 (i18n)**：完美支援**繁體中文 (Traditional Chinese)** 與 **英文 (English)** 雙語介面。套件能自動感應瀏覽器語系進行顯示，亦可在設定面板中手動切換。
* 🔍 **雙語搜尋與動態翻譯**：搜尋框支援中文及英文拼音（Pinyin）模糊搜尋全台縣市與鄉鎮區；天氣狀況 (Wx)、風向、空氣品質指標 (AQI) 等所有氣象資訊均提供高品質的雙語翻譯對照。
* 📍 **細緻定位**：支援全台灣 22 個縣市、所有鄉鎮市區（例如：台北市北投區、新北市新店區）。
* 🌦️ **即時天氣資訊**：提供當前溫度、體感溫度、相對濕度、降雨機率、風力級別與風向。
* 🌧️ **雨量防災警示（今日累積 / 時雨量自動切換）**：整合中央氣象署自動雨量站 API (`O-A0002-001`)，即時顯示今日累積降雨量。當偵測到過去 1 小時降雨量（時雨量）**達 30 mm 或以上**，UI 會自動切換並啟動**紅色呼吸燈閃爍警戒**。
* 🔔 **氣象警特報整合 (v2.3 新增)**：即時抓取中央氣象署官方警特報 API (`W-C0033-001`)，支援豪雨、強風、低溫、高溫、颱風等官方警示，並在主畫面以醒目的警告橫幅顯示，大幅提升防災資訊的可及性。
* 📊 **今日智慧摘要 (v2.3 新增)**：根據當前溫度、降雨機率、時雨量、AQI 及警特報，自動產生一句話摘要（如「午後有雨，出門記得帶傘 ☂️」、「空品良好，適合戶外活動 🌿」），讓使用者免去閱讀所有數據的麻煩，一眼掌握當日天氣重點。
* 🌿 **即時空氣品質 (AQI & PM2.5)**：自動媒合距您最近的環境觀測站，顯示即時 AQI 指數與 PM2.5 濃度。點擊 AQI 卡片可**展開詳細污染物數據** (v2.3 新增)：PM10、O₃、NO₂、CO、SO₂，以及依空氣品質等級給出的個人化健康建議。
* 📅 **一週預報（v2.3 視覺優化）**：直觀的 7 天天氣預報。明天特別突顯；降雨機率依高低以顏色分級（藍色低、紅色高）；每張預報卡右下角標示資料來源（`CWA` 黃標 / `OM` 藍標），透明度更高。
* 🎨 **療癒手繪設計**：精心調配的暖色系/深色系配色，搭配可愛的手繪風邊框與微動畫。
* 🔌 **API 金鑰快速測試 (v2.3 新增)**：設定面板新增「測試連線」按鈕，輸入 Key 後一鍵驗證是否有效，省去反覆儲存與重新整理的煩惱。
* 🏷️ **常用地區快速切換**：整合模糊搜尋框，打字即時篩選，一鍵儲存常用鄉鎮。
* 🌡️ **工具列圖示即時溫標**：免點開！瀏覽器工具列圖示直接大字顯示主地區的當前溫度，並根據氣溫自動變換背景顏色。
* ⚡ **省流快取與效能優化**：內建 Service Worker 背景定時快取機制（TTL 可自訂），避免重複請求氣象署 API。
* ✒️ **字型線上載入與優化 (v2.3.2 更新)**：改回使用 Google Fonts 線上連結加載 Fredoka 與 Outfit 英數字體，並移除高達 38MB 的本地 TTF/WOFF2 字型檔案，大幅縮減擴充功能的打包與安裝體積。
* ✍️ **中文字型易讀性與排版優化 (v2.3.2 更新)**：繁體中文模式下中文字型改用系統內建高清晰度黑體（如微軟正黑體、PingFang SC），並全面調大字級 (font-size) 1~2px。徹底解決先前 Thin 手寫字太小太細及重影模糊的問題。同時將「今日摘要」重新設計排版，移入當前天氣主卡片（主框）內，版面更協調、不顯擁擠。
* 📏 **彈出視窗排版與尺寸優化 (v2.3.3 新增)**：顯式將擴充功能彈出視窗高度加長至 595px，並微調收緊了外容器、標題、卡片間距、摘要條的 padding 與 margin (共縮減 38px 垂直無效空間)，完美解決了直向滾動條露出的問題，介面更乾淨清爽。
* 📐 **摘要並排與 UI 箭頭放大 (v2.3.4 新增)**：為徹底根除直向滾動條，重構當前天氣佈局，將當前溫度與圖示靠左，並將「今日摘要」以小巧精緻的虛線框並排於右上角（字體調小至 11px），省去整行垂直空間；同時將空氣品質卡底部展開的倒三角圖示 (Expand Arrow) 放大至 16px 並提高對比度，大幅提升操作便利性。
* 🎀 **今日摘要視覺微調 (v2.3.5 新增)**：為使介面更加融入，將右上角今日摘要的背景框與框線全面移除，直接以精簡字體顯示；同時移除文案尾端重複的天氣 emoji，僅保留前置的精緻小圖示，整體畫面更為乾淨素雅。
* 🌧️ **一週預報 100% 降雨率排版微調 (v2.3.6 新增)**：為防止當降雨機率達三位數（如 100%）時在一週預報的極窄卡片中發生折行跑版，將降雨率的字型大小微調至 9px，並將圖示與數字的間距縮減為 0px，確保在限寬 35px 內依然能完美在同一行內顯示。
* 🗜️ **視窗底邊空白縮減 (v2.3.7 新增)**：為解決前幾次佈局緊湊化後，在底部露出的多餘空白底板問題，將彈出視窗高度 (`body height`) 由 595px 進一步縮小至剛剛好的 **560px**，完美貼合預報底部並保留舒適呼吸感。

## 🛠️ 技術架構

* **前端核心**：HTML5, JavaScript (ES6+), Vanilla CSS（採用手繪風格卡片與靈活佈局）
* **擴充功能標準**：Chrome Extension Manifest V3
* **背景服務**：Service Worker (`background.js`)、Chrome Alarms API、Chrome Storage API
* **氣象數據來源**：中華民國交通部中央氣象署 (CWA) 開放資料 API（主數據源）
* **後半週降雨機率補充**：[Open-Meteo API](https://open-meteo.com/)（提供第 4~7 天的降雨機率，免申請金鑰）
* **空氣品質數據來源**：中華民國環境部 (MOENV) 開放資料 API

## 📦 安裝教學

1. **下載本專案**：
   * 點擊本倉庫右上角的 `Code` -> `Download ZIP` 並解壓縮，或者使用 Git 複製倉庫：
     ```bash
     git clone https://github.com/xiaomaowei/taiwan_weather_chrome.git
     ```
2. **開啟 Chrome 擴充功能頁面**：
   * 在 Chrome 網址列輸入 `chrome://extensions/` 並回車。
3. **啟用開發者模式**：
   * 將擴充功能頁面右上角的**「開發者模式」**開關切換為啟用。
4. **載入擴充功能**：
   * 點擊左上角的**「載入未封裝擴充功能」**按鈕。
   * 選擇本專案的解壓縮資料夾（包含 `manifest.json` 的該層目錄）。
5. **固定至工具列**：
   * 點擊 Chrome 右上角的拼圖圖示 🧩，找到「台灣天氣」，點擊圖釘按鈕將其固定在工具列，以便隨時查看即時溫度！

## 🔑 申請與設定 CWA API Key (氣象)

為了能順利獲取最即時的氣象資訊，建議設定您專屬的中央氣象署授權碼：

1. **申請授權碼**：
   * 前往 [交通部中央氣象署開放資料平台](https://opendata.cwa.gov.tw/index) 註冊免費帳號。
   * 登入後在個人帳戶的「取得授權碼」頁面中複製您的 `API Key` (格式如：`CWA-XXXXXX`)。
2. **在擴充功能中設定**：
   * 點開瀏覽器上的台灣天氣擴充功能。
   * 點擊右上角的**「齒輪」設定按鈕**展開設定面板。
   * 在「CWA API 授權碼」欄位貼上您申請的授權碼，點擊**「儲存設定」**。
   * *(註：本專案未預設金鑰，請務必填寫以獲取氣象資訊，或在設定中開啟「示範模式」進行體驗。)*

## 🔑 申請與設定 MOENV API Key (空氣品質)

本功能已新增即時空氣品質顯示，若要正常獲取最精確的 AQI 與 PM2.5 數據，建議設定您的環境部 API 金鑰：

1. **申請授權碼**：
   * 前往 [環境部開放資料平台](https://data.moenv.gov.tw/api-term) 註冊免費帳號並申請 API Key。
2. **在擴充功能中設定**：
   * 點開擴充功能，點擊右上角**「齒輪」設定按鈕**。
   * 在「環境部 API 金鑰」欄位中貼上您申請的 Key，並點擊**「儲存設定」**。
   * *(註：本專案未預設金鑰。若未設定金鑰，卡片會顯示「🌿 點此設定環境部 API 金鑰以顯示空氣品質」提示引導您完成設定。)*

## 📢 氣象資料限制與說明

* 💧 **一週預報降雨機率的資料融合**：
  * **前 3 天使用中央氣象署 (CWA) 官方數據**：依據中央氣象署逐 12 小時七天預報資料特性，降雨機率（ProbabilityOfPrecipitation）僅提供未來前 3 天的預測數值。本套件會優先顯示此官方數據。
  * **後 4 天（第 4~7 天）自動補充自 Open-Meteo API**：由於氣象署 API 在後半週資料集中不提供降雨機率，套件會依據您所選擇的鄉鎮市區座標，在背景自動向免金鑰的 **Open-Meteo API** 請求該地區的最大日降雨機率（`precipitation_probability_max`）來進行補充。
  * **降雨機率容錯設計**：若 Open-Meteo 請求失敗或網路異常，後半週降雨機率將會優雅降級顯示為 `💧--`，不會影響其他天氣資訊的呈現。

* 🌧️ **即時雨量數據說明**：
  * **資料來源**：中央氣象署自動雨量站觀測資料（`O-A0002-001`），更新頻率約每 **10 分鐘**一次。
  * **今日累積**：`RainfallElement.Now.Precipitation` 欄位，代表每天凌晨 **00:00 清零**後至當下的累積降雨量。
  * **時雨量警戒**：`RainfallElement.Past1hr.Precipitation` 欄位，代表過去 1 小時的累積降雨量。當時雨量 **≥ 30 mm**（達大雨至豪雨級別）時，UI 自動切換為顯示「時雨量」並啟動紅色呼吸燈警戒提示。
  * **雨量容錯設計**：若自動雨量站 API 請求失敗，雨量欄位會優雅降級顯示為 `-- mm`，不影響主天氣資訊的呈現。
  * **特殊代碼說明**：`T`（微量降雨，不足以計量）；`-98`（連續 6 小時無降雨，顯示為 0.0 mm）；`-99` / `X`（儀器故障或資料缺值，顯示為 0.0 mm）。

## 📂 專案檔案結構

```text
taiwan_weather_chrome/
├── _locales/             # 語系資源包
│   ├── zh_TW/            # 繁體中文語系 (messages.json)
│   └── en/               # 英文語系 (messages.json)
├── fonts/                # 本地字型（Fredoka、Outfit、辰宇落雁體）
├── manifest.json         # 擴充功能定義檔 (V3)
├── popup.html            # 擴充功能主視窗結構
├── popup.css             # 可愛手繪風格樣式表 (Light & Dark 雙主題)
├── popup.js              # 主視窗前端互動與 UI 渲染邏輯
├── background.js         # Service Worker，處理背景自動刷新與工具列 icon 繪製
├── city_county_data.js   # 台灣縣市與鄉鎮區資料對照表
├── i18n_data.js          # 多國語言翻譯對照表 (縣市、鄉鎮、天氣狀態、風向等)
├── icons/                # 擴充功能各尺寸圖示集
└── README.md             # 本說明文件
```

## 🎨 介面與主題切換

本套件支援**「手繪淺色主題」**與**「手繪深色主題」**。系統會根據您作業系統的深色模式設定自動套用，您也可以隨時在設定面板中手動切換：

* **淺色模式**：溫暖舒服的手繪羊皮紙米色底、炭灰色手繪線條與粉嫩的天氣插圖。
* **深色模式**：護眼的深夜黑板深藍底、明亮的手繪白線條。
